# Executable examples

Run `npm run build`, then `node examples/<name>.mjs`. Each example asserts its numerical or data-flow outcome and prints a small summary.

- `analyze-tone.mjs`: analyze tone
- `wav-roundtrip.mjs`: wav roundtrip
- `stream-chunks.mjs`: stream chunks
- `edit-stereo.mjs`: edit stereo
- `export-analysis.mjs`: export analysis
- `fourier-recovery.mjs`: fourier recovery
- `viewport-navigation.mjs`: viewport navigation

All signals are generated locally. No audio downloads or credentials are required.
